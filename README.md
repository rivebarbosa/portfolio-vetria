# Portfólio de Arquitetura — Vetria Distribuição

Terceiro caso de estudo do portfólio de arquitetura de soluções de Roberto Rivelino Barbosa, ao lado do PagFácil (github.com/rivebarbosa/portfolio-arquitetura) e do ArqFlow (github.com/rivebarbosa/portfolio-arqflow).

## Cenário

Vetria Distribuição é uma empresa fictícia de distribuição/logística B2B de porte médio, em expansão digital. O caso parte de um portfólio de aplicações internas que cresceu de forma orgânica — hoje todas em Azure App Service, sem relação direta entre si — para desenhar do zero a arquitetura de soluções: infraestrutura cloud, CI/CD, dados, segurança e operação.

## Estrutura

- `01-discovery` — contexto do negócio, situação atual, dores, stakeholders
- `02-requisitos` — requisitos funcionais e não funcionais que orientam as decisões
- `03-decisoes-arquiteturais` — ADRs (Architecture Decision Records)
- `04-diagramas` — diagramas C4 (draw.io)
- `05-trade-offs` — comparação de alternativas e trade-offs considerados
- `06-implantacao-e-operacao` — estratégia de deploy, CI/CD e operação
